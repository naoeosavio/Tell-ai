SUA IA, no terminal.

O Tell-ai leva modelos de linguagem para onde o seu código já vive: o shell. Pergunte, pipeie, scripte — a resposta chega em texto puro, pronta para o próximo comando.

tell-ai — sessão de exemplo

§ 01 — por quê

Copiar, colar, formatar, repetir.

fluxo — antes / depoisunified
--- a/fluxo/sem-tell-ai
+++ b/fluxo/com-tell-ai
1- abrir uma aba nova no navegador
2- digitar o endereço do chat
3- autenticar (de novo)
4- colar código + contexto à mão
5- copiar a resposta e reformatar
6- voltar ao editor e colar de novo
1+ tell "por que esse teste falha?" < output.log

~23 minutos

é o que estudos de atenção estimam para retomar o foco depois de uma interrupção. Cada ida até o navegador é uma delas. O Tell-ai encurta o caminho para um comando.

stdout é a interface

A resposta é texto puro: pode ir para um arquivo, um pipe, uma mensagem de commit, um cron — sem formatação para "limpar" antes de usar.

$TELL_KEY e pronto

Sem cadastro, sem tela de login, sem servidor no meio do caminho: a sua chave, no seu ambiente, no limite do seu plano.

§ 02 — primeiros passos

Três comandos até a primeira resposta.

01

Instale

Um binário, uma pergunta. Nada de daemon rodando em segundo plano.

$ npm install -g tell-ai
02

Aponte a chave

Só isso — sem cadastro, sem OAuth dance. A chave do ambiente que você já tem.

$ export TELL_KEY="sk-…"
03

Converse

E encadeie com tudo que você já usa: pipes, scripts, alias, cron.

$ tell "explique este traceback"

§ 03 — recursos

Construído como ferramenta unix.

TELL(1) · General Commands Manual

01--stream

Respostas token a token, direto no stdout — você lê enquanto o modelo gera.

02|

Pipes de verdade: git diff | tell "escreva a mensagem de commit".

03--model

Troque de provedor com uma flag: OpenAI, Anthropic, Gemini ou modelos locais via Ollama.

04@arquivo

tell @server.ts "ache o memory leak" — mencione arquivos e o contexto entra sozinho.

05~/.tellrc

Prompt de sistema, temperatura e aliases configurados uma única vez. Configure e esqueça.

06--history

Todo prompt e resposta num log local e pesquisável. Nada vai além do que você perguntar.

07$TELL_KEY

Sem conta e sem login. A chave do seu ambiente é a única credencial que existe.

§ 04 — demo

Experimente sem instalar.

visitante@tell-ai: ~ — demo interativa não conectado
